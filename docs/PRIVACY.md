# 隐私与数据公开说明

## 已公开的数据

本仓库公开了一份 1in8b.life 的生成人生数据：

- 角色：Daan Smit（生成角色）
- 国家：比利时 BEL
- 内容：身份、状态、健康、钱、家庭关系、工作/教育、抉择、时间线、文本快照、状态照片
- 年龄范围：0–82 岁

这是游戏生成的虚拟人生，不是现实人物。  
但数据中包含类似现实的姓名、家庭关系、健康、收入和选择，公开前已经由仓库所有者确认。

## 不包含的内容

- Chrome 用户配置目录
- Cookie
- 登录 Token
- Tampermonkey 存储
- 浏览器 Local Storage
- 其他人生
- 其他国家资料
- 其他网站数据

导出时只复制了 `1in8b.life` 的 IndexedDB 数据库，并在临时无头 Chrome 中读取；临时目录已删除或不在仓库内。

- 本仓库不是官方项目，与站点及 Jin’s Earth 无隶属关系
- 生成角色和游戏过程数据用于记录、研究和展示
- 代码使用 MIT 许可证；数据不单独授予额外许可证，使用前请自行确认权利和合规要求

## 公开后的不可逆性

GitHub 是公开仓库：

- 数据一旦推送，会进入 Git 历史
- 即使后续删除文件，历史提交仍可能保留
- 不适合放入任何真实个人信息、密钥或私密数据

## 建议

- 不要把真实姓名、联系方式、账号、Cookie、Token 放进同一个仓库
- 如果要复用本项目，建议使用自己的临时 Chrome 配置，不要提交浏览器数据
